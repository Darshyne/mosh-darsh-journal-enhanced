# mosh-darsh-journal-enhanced

Thèmes visuels custom pour JournalEntry, indépendants du système Mothership.
Architecture extensible par thème (themes/<nom>/). Thème actuel : Gradient
Descent. Voir CLAUDE.md pour le détail technique (MutationObserver, Range API,
pièges V13 rencontrés).
